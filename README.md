# Скетчбуки

Отсканированные скетчбуки, которые листаются как настоящие: разворот, обложка,
пружинный довод, стопка страниц под пальцем. И стена, на которой они стоят
между картинами.

## Два режима

У приложения одно тело и два лица, и это главное, что нужно про него знать.

| | Мастерская | Витрина |
| --- | --- | --- |
| Как запускается | `npm run dev` | собранный сайт на GitHub Pages |
| Где содержимое | IndexedDB браузера + папка на диске | готовые файлы `data/` рядом с сайтом |
| Что можно | заводить книжки, добавлять страницы, кадрировать, переставлять | смотреть и листать |

В том, что стоит в интернете, нет ни одной кнопки, которая пишет, и нет доступа
к диску. Поэтому содержимое меняется единственным способом: дома, а потом
`git push`. Отдельных паролей и настроек доступа для этого не нужно.

## Запуск дома

```
npm install
npm run dev
```

Откроется на http://localhost:5173. Один раз нажмите «Привязать папку»
и выберите `public/data` в этом же репозитории — дальше всё сохраняется туда
само, при каждой правке.

Папка на диске работает в Chrome и Edge; в Safari и Firefox такого API нет.

## Публикация

```
npm run build     # соберёт сайт в dist, попутно обновит data/index.json
npm run preview   # посмотреть собранную витрину так, как её увидят другие
```

На GitHub это делается само: `.github/workflows/pages.yml` собирает сайт на
каждый push в `main` и выкладывает на Pages. Значит, весь ритуал публикации —
это

```
git add -A && git commit -m "новые страницы" && git push
```

## Как устроено

- **React + Vite**, без бэкенда.
- Дома всё лежит в IndexedDB и дублируется в папку `public/data`: `book.json` —
  текст, он нормально диффится, а картинки пишутся один раз и больше не
  переписываются. Кадрирование и повороты живут числами в `book.json`, поэтому
  правка страницы не порождает новый мегабайт в git.
- Сканы ужимаются до 2400 px по длинной стороне (JPEG q0.9) плюс миниатюра
  480 px — её же берёт телефон и лента страниц. EXIF-ориентация применяется сама.
- На витрине вместо картинки в памяти лежит адрес файла, поэтому полка
  открывается мгновенно, а страницы подтягиваются по мере листания.

### Файлы

| Файл | Что делает |
| --- | --- |
| `src/lib/mode.js` | различает мастерскую и витрину |
| `src/lib/library.js` | одна дверь к содержимому для обоих режимов |
| `src/lib/site.js` | чтение витрины: `index.json` и `book.json` |
| `src/lib/db.js` | IndexedDB: скетчбуки и страницы |
| `src/lib/exchange.js` | запись в папку и чтение из неё |
| `src/lib/folder.js` | привязанная папка и права на неё |
| `src/lib/images.js` | подготовка сканов, миниатюры, object-URL'ы |
| `src/lib/flip.js` | движок листания: жесты, инерция, пружина |
| `src/lib/pdf.js` | вся книжка одним PDF |
| `src/components/Shelf.jsx` | стена с полками, на телефоне — список |
| `src/components/BookView.jsx` | экран листания |
| `src/components/PageEditor.jsx` | правка страницы: размер, поворот, кадр |
| `src/components/PageZoom.jsx` | страница во весь экран |
| `scripts/build-index.mjs` | собирает `data/index.json` перед сборкой |

## Управление

| Действие | Как |
| --- | --- |
| Листать | протянуть мышью или пальцем, флик пролистывает несколько страниц |
| Листать | стрелки ←/→, PageUp/PageDown, Home/End |
| Листать | горизонтальная прокрутка на трекпаде (или Shift + колесо) |
| Рассмотреть страницу | клик по ней: дома откроется правка, на витрине — крупный показ |
| Перейти к странице | миниатюра в ленте внизу или в обзоре «Все страницы» |
| Выйти на полку | Escape |
