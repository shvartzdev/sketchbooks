# Содержимое

Сюда приложение складывает скетчбуки — эта папка и есть хранилище.

    <скетчбук>/book.json      описание: формат, год, страницы, рамки, кадры
    <скетчбук>/images/*.jpg   изображения как есть
    <скетчбук>/thumbs/*.jpg   миниатюры для ленты и телефона
    art/*.jpg                 работы, которые висят на стене
    index.json                сводка полки, собирается сама при сборке сайта

Ничего здесь не нужно править руками: всё пишет приложение, запущенное
через `npm run dev`, когда эта папка привязана кнопкой «Привязать папку».
