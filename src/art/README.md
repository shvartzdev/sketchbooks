# Картины

Сюда кладутся ваши работы — обычные `.jpg`, `.png` или `.webp`.
Что положено, то и стоит на полках рядом с книжками; список собирается
автоматически при запуске (после добавления файла перезапустите `npm run dev`,
если Vite не подхватит сам).

Размер по умолчанию — A3 (два листа A4, 297×420 мм): в масштабе шкафа картина
получается заметно крупнее любого скетчбука. Чтобы задать свой размер, назовите
файл с размерами в миллиметрах через `x`, например:

    kaliningrad-297x420.jpg
    bolshaya-500x700.jpg
